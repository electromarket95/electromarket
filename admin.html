Панель управления товарами
Автоматическая публикация. Один раз подключите GitHub токен с доступом только к этому репозиторию. После этого добавление, изменение цены, описания, фото и удаление будут сразу отправляться на сайт. Пароль от GitHub сюда не вводите.

Подключение

Создаётся один раз в GitHub: Settings → Developer settings → Fine-grained tokens. Выберите только репозиторий electromarket и разрешение Contents: Read and write.
