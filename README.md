# ЭлектроМаркет — сайт-каталог

Адаптивный статический сайт-каталог для бесплатного размещения на GitHub Pages.

## Возможности
- Мобильная и настольная версии
- Поиск по названию, бренду, категории и описанию
- Категории и сортировка
- Карточки товаров с ценой, старой ценой, меткой, фото и описанием
- Корзина с изменением количества и подсчётом суммы
- Формирование заказа и открытие WhatsApp с заполненным сообщением
- Товары редактируются в `products.js`; сборка и сервер не нужны

## Перед публикацией
1. Откройте `products.js` и замените демонстрационные товары на реальные.
2. Проверьте цены, наличие, описания и изображения.
3. Номер WhatsApp сейчас задан в `app.js`: `79298881157`. Для изменения используйте международный формат без `+`, пробелов и дефисов.
4. Добавляйте фотографии в папку `assets/`, например `assets/redmi-note.jpg`, а в товаре укажите `image: "assets/redmi-note.jpg"`.
5. Проверьте заказ тестовым товаром. На финальном шаге сайт открывает WhatsApp; сообщение нужно отправить вручную.

## Как добавить товар
В `products.js` добавьте объект внутрь `window.PRODUCTS`, через запятую после предыдущего объекта:

```js
{
  id: "phone-003",
  name: "Название товара",
  brand: "Бренд",
  category: "Смартфоны",
  price: 19990,
  oldPrice: 21990,
  badge: "Акция",
  emoji: "📱",
  image: "assets/phone-003.jpg",
  description: "Короткое описание товара."
}
```

`id` должен быть уникальным. Цена — числом без пробелов и символа ₽. Допустимые категории:
- `Смартфоны`
- `Аксессуары`
- `Планшеты и компьютеры`
- `Электроинструменты`
- `Бытовая техника`
- `Кондиционеры`
- `Смарт-гаджеты и сеть`

Для товара без скидки укажите `oldPrice: 0`, для товара без фотографии — `image: ""`. Используйте изображения, на которые у вас есть право.

## Публикация на GitHub Pages
1. Войдите в GitHub и создайте новый **Public** репозиторий, например `electromarket`.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js`, `products.js`, а папку `assets` — если есть фотографии.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В **Branch** выберите `main`, папку `/ (root)`, затем нажмите **Save**.
6. Подождите завершения публикации. GitHub покажет адрес примерно такого вида:
   `https://ВАШ-ЛОГИН.github.io/electromarket/`
7. После изменения товаров или дизайна загрузите обновлённые файлы в репозиторий — GitHub Pages обновит сайт автоматически.

## Важно
- GitHub Pages бесплатен для публичных репозиториев; домен можно подключить отдельно.
- Каталог работает на стороне браузера. Нет автоматической синхронизации остатков, онлайн-оплаты, CRM или закрытой админ-панели.
- Цены в шаблоне демонстрационные. Перед публикацией замените их реальными ценами магазина.
- Не добавляйте в этот статический сайт пароли, секретные ключи и приватные данные.
